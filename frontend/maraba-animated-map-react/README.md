# Animated Marabá Map

Copie `AnimatedMarabaMap.jsx`, `AnimatedMarabaMap.css` e a pasta `assets` para seu projeto React.

Uso:
```jsx
import AnimatedMarabaMap from "./AnimatedMarabaMap";
<AnimatedMarabaMap />
```

A imagem incluída é a captura enviada na conversa e serve como protótipo/alinhamento.
Para produção, substitua por uma imagem/cartografia que você tenha direito de usar.
